# WRJ Lookbook

Search WRJ Design's interior photography in plain language — "vaulted ceiling
kitchen", "walnut vanity" — instead of digging through folders. Find similar
photos, collect them into shared Boards or private Stashes, and present them
full-screen.

Internal tool: needs WRJ network access. Installer only — the source is private.

## Install

1. Download the latest setup `.exe` from
   [Releases](https://github.com/hennerdenner/WRJ-Lookbook/releases/latest).
2. Windows will warn **"Windows protected your PC"** — the installer isn't signed
   yet. Click **More info → Run anyway**.
3. Launch from the Start menu. The first run takes a minute.

Needs Windows 10 or 11 (64-bit) and Egnyte Drive signed in.
